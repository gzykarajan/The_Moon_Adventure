# 月球探险 The Moon Adventure

一个给 6 岁儿童玩的电脑浏览器 3D 月球车探险游戏。玩家以第一视角驾驶月球车在月面自由寻找 10 位不同外星朋友，每位朋友会出一道小学一年级难度选择题。答对后这位外星朋友会消失并奖励一颗星，收集 10 颗星后通关。

## 一键启动

双击 `run.bat`。

脚本会自动：

1. 检查本机 Node.js 和 npm。
2. 第一次运行时执行 `npm install`。
3. 打开 `http://127.0.0.1:5173`。
4. 启动本地 Vite 游戏服务器。

也可以手动运行：

```bash
npm install
npm run dev
```

## 操作

- 驾驶模式：`↑` 前进，`↓` 后退，`←` / `→` 按当前车头方向转向。
- 答题模式：`←` / `→` 切换 A/B/C/D，`Space` 确认。
- 音乐：右上角音乐按钮开启或停止，默认尝试开启。游戏会按文件名顺序循环播放 `assets/BGM/` 下的所有 `.mp3` 文件；浏览器若拦截自动播放，按任意键或点击页面后会继续播放。

## 探险规则

- 10 位外星朋友分布在月球表面，玩家可以自由选择先找哪一位。
- 靠近任意尚未完成的外星朋友会触发答题。
- 答对后该外星朋友从场景中消失，不再触发题目。
- 答错会立即换一道不同题目，直到答对才能退出答题模式。
- 屏幕上的进度显示已完成外星朋友数量和已获得星星数量。

## 画面方向

本游戏只面向电脑浏览器游玩。场景使用程序化月面：高低起伏地形、大小陨石坑、坑沿、散落月岩、月尘颗粒、星空和远处地球。整体亮度保持柔和，避免频闪和刺眼高饱和颜色。

## 题库维护

题库放在 `public/questions/`：

- `pinyin.json`：拼音
- `math.json`：数学
- `chinese.json`：认字
- `english.json`：英语

每道题格式：

```json
{
  "id": "math-01",
  "question": "3 + 2 = ?",
  "options": ["4", "5", "6", "7"],
  "answer": 1
}
```

`answer` 是正确选项下标，`0` 表示 A，`1` 表示 B，`2` 表示 C，`3` 表示 D。

## 音乐维护

把 `.mp3` 文件放入 `assets/BGM/`，游戏会在下次启动或刷新后自动加入背景音乐循环播放列表。

## 技术栈

- Node.js 本地运行环境
- Vite 本地开发服务器
- Three.js WebGL 3D 渲染
- 原生 JavaScript/CSS/HTML
- JSON 可编辑题库

## 验证

```bash
npm run build
```

构建通过后，说明依赖、模块导入和静态资源打包可正常工作。
